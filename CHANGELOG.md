# Changelog

## [1.0.0] — 2026-06-09

### Added
- Initial release
- Wallpaper rotation with configurable interval (default 45s)
- 8 built-in themes: anime, ai, cybersec, dev, science, music, data, mixed
- `--theme` flag to select a theme
- Systemd user service for autostart
- TOML config file (`~/.config/wallpaper-changer.toml`)
- Multi-desktop support: GNOME, KDE, Sway, i3, XFCE, Cinnamon, MATE, Hyprland
- `--list-themes` to display available themes
- CLI flags: `--dir`, `--interval`, `--no-dark`
- Sample wallpapers included (18 images per theme)
